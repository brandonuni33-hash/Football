# PR9 — Points de review

La review doit chercher en priorité les régressions suivantes: retour d'un auto-avancement narratif; nombre de décisions figé; chrono sur un match banal; geste technique proposé sans contexte/capacité; expiration transformée en choix automatique; but créé par l'UI; mélange de `matchId`; rapport froid centré sur les pourcentages; réactions génériques ou provenant d'un autre match.
