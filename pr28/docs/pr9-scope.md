# PR9 — Scope figé avant review

Cette branche ne traite que l'expérience du match jouable.

**Inclus:** rythme manuel, décisions variables, pression chronométrée exceptionnelle, expiration comme conséquence, profil technique/origine, gestes contextuels, mémoire et chaîne de conséquences intra-match, identité `matchId`, modèle de célébration de but canonique, séparation des appellations du bloc, rapport centré sur le tournant, réactions à voix distinctes.

**Hors scope:** arcs narratifs de carrière, famille, transferts, génération suivante, économie, progression générale et refonte du coach hors réactions immédiates du match.

La PR ne doit être mergée qu'après tests unitaires + Playwright + Architecture Check verts.
