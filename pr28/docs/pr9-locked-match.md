# Match dominé ou verrouillé

La plage de décisions n'est pas une obligation de remplir le match. Un match fermé peut produire peu de fenêtres et leur donner plus de poids. Un match largement dominé peut également réduire l'intérêt de décisions artificielles. Le moteur doit préférer une décision significative à trois choix de remplissage; les plages définissent une cible par type, pas une excuse pour fabriquer des occasions qui n'existent pas dans l'histoire du match.
