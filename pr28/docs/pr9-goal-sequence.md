# Séquence de but PR9

Ordre obligatoire: le domaine résout le match → un but du joueur existe dans les faits canoniques → un événement de présentation reçoit `matchId`, minute, buteur, score et geste éventuel → l'overlay plein écran s'affiche → le joueur appuie sur « Continuer » → le récit reprend. L'overlay ne possède aucune API pour ajouter un but aux statistiques ou au score.
