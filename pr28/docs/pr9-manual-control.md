# Contrôle manuel et chronomètre

Il n'y a pas de contradiction entre les deux règles:

- une **scène** attend toujours « Continuer »;
- une **décision normale** attend toujours le choix du joueur;
- une **décision explicitement sous pression** peut expirer après quelques secondes;
- l'expiration n'appuie sur aucun bouton à la place du joueur: elle produit « hésitation / occasion perdue »;
- les petites animations visuelles peuvent vivre seules, mais ne peuvent jamais faire passer le match à la scène narrative suivante.
