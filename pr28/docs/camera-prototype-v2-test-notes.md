# Camera V2 mobile checklist

Test in landscape:

1. Does the camera feel attached to the ball rather than the controlled player?
2. Is the player still easy to identify while the ball moves away?
3. Are NORMAL -> COUNTER -> DANGER -> SHOT zoom changes progressive enough?
4. Does a shot remain readable without the camera snapping?
5. Adjust only after feel-testing; no V2 values are final yet.
