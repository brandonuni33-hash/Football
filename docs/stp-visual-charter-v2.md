# STP — Charte visuelle V2

Le ratio 70–80 % crédible / 20–30 % manga concerne surtout l'avatar standard et l'identité générale. Les scènes émotionnelles peuvent être plus stylisées lorsque le récit le justifie.

Ne pas présenter des coiffures irréalistes comme norme de base.

Le marketing peut amplifier l'intensité, jamais modifier l'identité visuelle.

L'âge transforme le joueur sans remplacer son identité. Le portrait manga porte l'essentiel du vieillissement ; le sprite 2D reste plus simple.
