# STP Avatar — évolution visuelle avec l'âge

Principe : l'âge transforme le joueur sans remplacer son identité.

Étapes visuelles : 14–16 adolescent ; 17–20 jeune joueur ; 21–27 pleine maturité ; 28–33 joueur expérimenté ; 34+ vétéran.

L'identité stable conserve notamment le teint, les traits distinctifs, la coiffure choisie, les couleurs, les accessoires et le gabarit de référence. Le vieillissement agit surtout sur la maturité du visage, la mâchoire, le développement corporel, la densité potentielle de barbe et, tardivement, les rides d'expression.

Le portrait manga est le support principal du vieillissement. Le sprite 2D n'en reprend que les indices nécessaires à la lisibilité.

Le système de données doit séparer `appearance` (identité/cosmétiques) de `ageAppearance` (âge/stade visuel).
