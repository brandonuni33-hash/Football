# Invariants non négociables PR9

- Continuer est manuel pour toute scène narrative.
- Chrono seulement sur une décision explicitement sous pression.
- Zéro seconde = occasion perdue, jamais choix automatique.
- Nombre de décisions variable, jamais « exactement deux ».
- Une option spectaculaire doit être disponible avant d'être racontée.
- Origine = affinité; attributs + contexte = capacité réelle.
- Chaque décision peut produire immédiat / évolution / différé / stats / narration.
- Un but visuel existe seulement après validation canonique.
- Un récit détaillé = un seul `matchId`.
- « Ton match » n'est pas synonyme de « meilleure performance ».
- Réactions = voix différentes + fait précis.
