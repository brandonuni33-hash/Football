# Exemples de décisions sous pression

**90+2, finale, 1–1** — ballon repoussé à l'entrée de la surface, défenseur qui revient: 4–7 secondes selon mental.

**Derby, 84e** — duel déjà chauffé par plusieurs provocations, ballon dans le couloir: chrono possible.

**Match ordinaire, 25e** — même si l'action est dangereuse, pas de chrono par défaut: le joueur doit pouvoir réfléchir.

Le chrono représente une fenêtre footballistique qui se ferme, pas une punition arbitraire du joueur humain.
