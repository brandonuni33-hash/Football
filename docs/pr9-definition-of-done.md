# PR9 — Definition of Done

La reprise de PR9 est terminée uniquement si:

1. le joueur peut laisser une scène affichée sans qu'elle disparaisse;
2. les plages de décisions varient selon le type de match;
3. les chronos sont absents des matchs ordinaires et exceptionnels seulement quand la situation le justifie;
4. expiration, réussite et échec sont enregistrés comme faits de la session;
5. l'identité technique/origine influence les options et probabilités;
6. les conséquences peuvent revenir plus tard dans le même match;
7. aucun visuel de but ne peut créer un but;
8. toutes les surfaces détaillées du match utilisent le même `matchId`;
9. les appellations du bloc ne confondent pas match joué et meilleure performance;
10. le rapport et les réactions parlent de faits précis;
11. les tests unitaires, Playwright et Architecture Check sont verts.
