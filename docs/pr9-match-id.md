# `matchId` — invariant principal

Un bloc peut contenir plusieurs résultats, mais un seul match peut posséder le récit interactif détaillé. Score, décisions, événements, buts présentés, rapport et réactions détaillées doivent tous porter le `matchId` de cette session. Les matchs simulés restent dans « Résultats du bloc » et peuvent être « meilleure performance », mais ne peuvent jamais fournir un fait au récit de « Ton match ».
