# Modèle de conséquence PR9

Chaque choix peut alimenter cinq couches sans que toutes soient spectaculaires:

1. **Immédiat** — réussite, perte, faute, tir, passe.
2. **Match** — défense qui recule, pression, espace, nervosité.
3. **Différé** — une situation précédente revient plus tard.
4. **Statistique** — note, fatigue, but, passe, carton.
5. **Narratif** — hooks propres que coach, vestiaire, médias/supporters pourront commenter à partir du même `matchId`.

Une conséquence narrative ne doit jamais inventer le résultat mécanique qui la précède.
