# Rapport PR9

Le rapport répond à « qu'est-ce qui s'est passé et qu'est-ce que cela a changé ? ». Priorité: tournant, influence, décision décisive, duel/geste, évolution tactique, conséquence pour la suite. La note et les pourcentages peuvent exister ailleurs dans l'interface mais ne structurent pas le récit. Si « Ton match » est aussi la meilleure performance, l'interface doit le signaler plutôt que dupliquer deux rapports.
