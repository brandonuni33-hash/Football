# À observer pendant le test PR9

Le test joueur devra surtout répondre à cinq questions: est-ce que tu as le temps de lire; est-ce que deux matchs semblent vraiment différents; est-ce qu'un choix précédent revient naturellement plus tard; est-ce que les gestes proposés ressemblent à ton joueur; est-ce que le rapport te rappelle un moment du match plutôt qu'une feuille de statistiques. Tout retour doit être rattaché à l'un de ces axes avant d'élargir le scope.
