# Vertical Slice content

Ce dossier contient uniquement les données éditoriales validées pour la vertical slice.

Il ne possède ni la simulation, ni les conséquences métier, ni le pacing runtime principal.

- `pastFragments.js` : souvenirs/questions du passé ;
- `prologueScenes.js` : premières scènes et contrat de présentation narratif.

Toute interprétation en traits cachés ou toute conséquence durable doit être réalisée par une couche d'orchestration séparée.
